# NGO Aid Distribution Accountability System

ASP.NET Core MVC web application for managing NGO aid requests.

## Features
- User Registration/Login
- Role-based Access (Admin/User)
- Aid Request Submission
- Request Approval/Rejection
- Dashboard Management
- Request Filtering/Search
- Responsive UI

## Technologies
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- Bootstrap
## Description
This project is an enterprise-level ASP.NET Core web application designed to manage NGO aid distribution efficiently and transparently.

##  Objectives
- Ensure fair distribution of aid
- Prevent duplication of aid delivery
- Improve transparency and accountability





## 📂 Project Structure
- Models
- Views
- Controllers

## 📊 System Focus
This system focuses on logistics, verification, and transparency by recording deliveries, locations, teams, and timestamps while maintaining strong audit trails.
