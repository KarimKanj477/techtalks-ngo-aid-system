# NGO Aid Distribution Accountability System

ASP.NET Core MVC web application for managing NGO aid requests and improving aid distribution transparency.

---

## Project Overview

This system allows users to submit aid requests while administrators can manage, review, approve, reject, edit, and monitor all requests through an admin dashboard.

The project was developed using ASP.NET Core MVC with Entity Framework Core and Bootstrap.

---

## Features

### User Features
- User Registration & Login
- Role-based Authentication
- Submit Aid Requests
- View All Requests
- Track Personal Requests
- Responsive User Dashboard

### Admin Features
- Admin Dashboard
- Manage Aid Requests
- Approve / Reject Requests
- Edit & Delete Requests
- Search Requests
- Filter Requests by Status
- Manage Users
- Request Statistics
